Excellente question Adem ! 🚀 Voici l'essentiel pour bien démarrer :

check_circle

StatelessWidget : Son état est immuable. Son affichage ne change pas au cours du temps (ex : Text, Icon, boutons statiques).

change_circle

StatefulWidget : Il possède un objet State mutable. Il se redessine dynamiquement via setState() quand les données évoluent (ex : compteur, formulaires).

counter_example.dart 
class Counter extends StatefulWidget {
  const Counter({super.key});

  @override
  State<Counter> createState() => _CounterState();
}

class _CounterState extends State<Counter> {
  int _count = 0;

  void _increment() {
    setState(() => _count++); // Rebuilds UI
  }

  @override
  Widget build(BuildContext context) {
    return ElevatedButton(
      onPressed: _increment,
      child: Text('Clics : $_count'),
    );
  }
}
